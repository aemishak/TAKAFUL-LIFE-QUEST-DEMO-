# Takaful Life Quest 3D

Game papan 3D (Three.js). Satu fail `index.html`, tiada build step.

## Deploy ke GitHub Pages
1. Upload `index.html` (dan `.nojekyll`) ke root repo.
2. Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
3. Tunggu 1–2 minit, game ada di `https://<username>.github.io/<nama-repo>/`.

## Nota
- Perlukan internet (Three.js dan font dimuat dari CDN).
- Pilihan bahasa dan progress game disimpan dalam browser (localStorage).
